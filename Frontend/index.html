Documentation & About

System Architecture Overview

This system implements a Dual Model Feature Fusion (DMFF) approach for Environmental Sound Classification. Raw audio is preprocessed and split into two extraction pathways: a Linear Spectral Map (Log-Mel Spectrogram) and a Non-Linear Dynamic Map (Recurrence Plot). These features are fused using Spatial Feature Scanning and Cross-Feature Enhancement before classification.
