About this system

System architecture

This system implements a Dual Model Feature Fusion (DMFF) approach for environmental sound classification. Raw audio is preprocessed and split into two pathways: a linear spectral map (Log-Mel Spectrogram) and a non-linear dynamic map (Recurrence Plot). The two are fused using Spatial Feature Scanning and Cross-Feature Enhancement before classification.

How to use

  1. Select a neural network from the dropdown.
  2. Record a sound with the microphone, or upload an audio file (e.g. .wav).
  3. Click Analyze Sound.
  4. Review the prediction, its confidence and the generated feature maps.
